**Author:** Marco Martinez

**Project:** Personal Online Resume

## Project Overview

This project is a one-page online resume created using HTML5 and CSS3. The purpose of the website is to showcase my education, technical skills, experience, and projects while demonstrating my knowledge of web development and accessible website design.

The resume focuses on my interests in web development, IT support, and Linux system administration.

## Technologies Used

- HTML5 – Semantic webpage structure
- CSS3 – Website styling and responsive layouts
- Git and GitHub – Version control
- GitHub Pages – Website hosting

## Website Features

- Professional resume layout
- Responsive design for desktop and mobile devices
- Accessible navigation and semantic HTML
- Professional overview and career objective
- Technical skills and relevant coursework
- Experience, education, and project highlights
- Volunteer and community involvement section

## Project Files

- `index.html` – Main resume webpage
- `style.css` – Stylesheet for the website
- `README.md` – Project documentation
